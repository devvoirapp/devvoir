# Devvoir Roadmap

## Phase 1 — Complete the Core (High Value, Low Complexity)

- [x] Date range filter for reports
- [x] Branch selection for reports
- [x] Export report as Markdown file / PDF
- [x] Custom report tone and length (e.g. brief standup vs. detailed summary)

---

## Phase 2 — Growth & Retention (Differentiators)

- [ ] Shareable report links (public read-only URLs)
- [ ] Email digest — daily or weekly report delivered to inbox
- [ ] Slack integration — post report directly to a channel

---

## Phase 3 — Deferred (Revisit After Growth)

- [ ] Team workspaces and manager view
- [ ] Commit-based reports (not just PRs)
- [ ] Webhook support (trigger on PR merge)
- [ ] GitHub Actions integration
- [ ] Multiple GitHub account connections
- [ ] Usage analytics dashboard
